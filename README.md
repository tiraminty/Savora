# 🍽️ Savora

> A modern restaurant website built to showcase a premium dining experience through clean design, responsive layouts, and subtle interactions.

## ✨ Overview

Savora is a fictional modern restaurant website created as a portfolio project.

The goal was to build something that feels like a real client website rather than a simple HTML/CSS practice project.

The design focuses on:

- Elegant typography
- Warm restaurant-inspired colors
- Responsive layouts
- Smooth interactions
- Clear navigation
- Mobile-first usability
- Clean and maintainable code

---

## 📄 Pages

| Page | Description |
|------|-------------|
| 🏠 Home | Hero section, restaurant introduction, featured content and chefs |
| 🍽️ Menu | Restaurant dishes and menu categories |
| 👨‍🍳 About | Restaurant story, values and team |
| 📍 Contact | Contact information and contact form |

---

## 🛠️ Built With

- **HTML5** for structure
- **CSS3** for styling and responsive layouts
- **JavaScript** for interactions
- **Google Fonts** for typography

No frameworks were used.

The project was built from scratch to strengthen fundamental web-development skills.

---

## 🎨 Design

Savora uses a warm, elegant visual identity designed around a premium restaurant atmosphere.

### Main design ideas

- Dark neutral tones
- Gold accent color
- Spacious layouts
- Large imagery
- Rounded cards
- Subtle hover animations
- Responsive typography

---

## 📱 Responsive Design

The website was tested across different viewport sizes, including:

- Desktop
- Tablet
- Mobile
- 375px mobile viewport

Special attention was given to:

- Navigation
- Chef cards
- Menu cards
- Contact cards
- Footer layout
- Text wrapping
- Image sizing
- Horizontal overflow
